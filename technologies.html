Lead Developer • Geospatial AI & Computer Vision

AI-Powered Georeferenced Road Extraction & Interactive Editing Platform

An end-to-end geospatial artificial intelligence platform that automatically extracts pixel-level road networks from high-resolution satellite imagery and enables real-time interactive topological repair.

  • End-to-End GeoAI Segmentation: Trained a multi-encoder (EfficientNet-B3 / ResNet50) U-Net segmentation architecture using Segmentation Models PyTorch (SMP) with hybrid Dice + Focal loss and Albumentations, achieving an 84.3% IoU score.
  • Interactive Road Repair & Tiling: Engineered an interactive repair module combining Test-Time Augmentation (TTA), Laplacian gradients, and Dijkstra / A* shortest-path algorithms to bridge fragmented road segments in real time. Implemented 512px overlapping sliding-window inference (stride: 128px) with probability stitching to process 1GB+ GeoTIFFs without GPU OOM errors.
  • Lossless Georeferencing: Preserved CRS projections and Affine transformation matrices via Rasterio (GDAL) alongside an asynchronous FastAPI background task queue for seamless QGIS & ArcGIS compatibility.
PyTorch SMP (U-Net) FastAPI React & TypeScript Rasterio / GDAL OpenCV Scikit-Image HTML5 Canvas

REZIT – Next-Gen SaaS Interactive Table Reservation Platform

A high-concurrency SaaS reservation platform that allows customers to interactively inspect venue layouts and select their exact table before arriving at the venue.

  • Scalable Backend Architecture: Built from scratch with Node.js, Express.js, and PostgreSQL utilizing B-Tree indexing and pg-pool connection pooling to reliably handle 500+ concurrent requests/sec under peak load.
  • Transaction Safety & Interactive Floorplan Editor: Eliminated double-bookings and race conditions via ACID transactions and pessimistic row-locking (SELECT FOR UPDATE). Designed an interactive React template editor and SVG/HTML5 Canvas seat-mapping module powered by affine matrix transformations (smooth zoom/pan).
  • Enterprise Security Infrastructure: Integrated stateless JWT authentication, strict CORS policies, Express Rate-Limiter layers, and Express-Validator endpoint sanitization against SQL injection.
